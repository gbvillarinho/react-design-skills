# react-design-skills

Claude Code skills for building better React front-ends. They work together: `ui` for how it looks, `ux` for how it works, `a11y` so everyone can use it, and `copy` for the words.

| Skill | What it covers |
| --- | --- |
| [`ui`](ui/SKILL.md) | Visual identity, typography, color, layout, motion. Avoids template-looking interfaces. |
| [`ux`](ux/SKILL.md) | Nielsen's heuristics, hierarchy, flows, screen states, forms, microcopy. |
| [`a11y`](a11y/SKILL.md) | WCAG 2.2 AA, keyboard and focus, semantics and ARIA, contrast, motion. |
| [`copy`](copy/SKILL.md) | Page and product text that sounds human, in Portuguese and English. |

Each skill has a `SKILL.md` and a `references/` folder with deeper material.

## Install

Copy the skills you want into your skills folder:

```bash
git clone https://github.com/gbvillarinho/react-design-skills.git
cp -R react-design-skills/{ui,ux,a11y,copy} ~/.claude/skills/
```

Use `.claude/skills/` inside a project to enable them for that project only.
